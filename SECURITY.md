# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report privately through GitHub Security Advisories:
https://github.com/nekonaru/skiff/security/advisories/new

Include:

- The Skiff version (`skiff --version`)
- Steps to reproduce
- What you expected to happen and what actually happened
- Your assessment of impact, if any

You will get an acknowledgement within 7 days. There is no bug bounty; credit is given on request in the release notes.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Response process

Triage within 7 days, fix as a patch release, publish an advisory when a fix is out. If the issue affects previously released versions, the advisory lists them all.
